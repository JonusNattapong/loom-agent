# Loom V1.0 planning note

V1.0 should stabilize and productize the durable Loom platform rather than add another infrastructure layer.

Priorities:

- stable public runtime, provider, tool, skill, Bot, remote-worker, and scheduler contracts;
- configuration/schema/version compatibility and migration guarantees;
- release packaging and installation experience;
- completed operator workflows and observability polish;
- a small agent application SDK and unified execution APIs;
- foundations for Agent Arena/Godot integration, keeping Loom as the durable decision/orchestration layer and Godot as the real-time simulation layer.

V1.0 does not imply per-frame LLM movement control or retroactively expand V0.9 into P2P, relay, mesh, HA, or distributed storage infrastructure.


## Implementation status (V1.0 branch)

This section records what was actually implemented on the `agent/loom-v1`
branch. V1.0 stabilizes existing durable capabilities into a public, installable
platform; it does **not** add a new distributed-systems subsystem.

### Done
- **`@loom-agent/sdk` (1.0.0)** — stable public SDK: `defineAgent`, `defineTool`,
  `defineSkill`, `defineBot`, `createLoomApp`, `defineLoomApp`, `LoomApp`,
  stable contract types, and `SDK_API_VERSION` / `PROTOCOL_MAJOR` /
  `SCHEMA_VERSION`. Heavy runtime packages are optional peer dependencies
  loaded lazily by `run()` / `start()`.
- **`@loom-agent/config` (1.0.0)** — versioned schema (`schemaVersion: 1`), helpful
  validation errors, precedence CLI > env > project > user > defaults,
  `writeStarterConfig`.
- **CLI productization** — `loom init`, `loom doctor` (`--json`), `loom
  version` / `--version`, `loom config validate`, `--json` structured output on
  inspection commands.
- **Control API `/api/v1`** — hardened contract + OpenAPI 3.0 document
  (`packages/control/openapi.json`); `LoomClient` HTTP client.
- **Agent Arena** — `WorldAdapter` / `FakeWorldAdapter` foundation
  (experimental); examples.
- **Remote protocol** — `PROTOCOL_MAJOR = 1`; mismatched major rejected.
- **Tests** — 35 files / 166 tests (baseline 30/133). New: SDK (7), config
  (9), control API compatibility, SDK API snapshot, WorldAdapter.
- **Packaging** — external install smoke test passes (SDK installs with only
  its static deps; heavy runtime is optional peers). `npm audit` 0 vulns.
  `npm run eval` passes.

### Explicitly out of scope (unchanged from plan)
Multi-controller HA, distributed consensus/storage, mesh/overlay networking,
NAT traversal, STUN/TURN/ICE relay, and universal exactly-once external side
effects.
